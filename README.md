# KEŞİF

Türkiye'de başlayan, gençlere günün o anında neye ihtiyaç duyduklarına göre keşif önerileri sunmayı hedefleyen platformun ilk çalışan arayüzü.

## Bu ilk sürümde neler çalışıyor?

- Dört farklı ihtiyaç modu ile değişen içerik kartları
- Kart başlığı/açıklaması içinde arama
- Günlük öneriyi yenileme
- Kart ayrıntı penceresi
- Tarayıcıda kalıcı favori listesi
- Basit odaklanma başlangıcı
- Bağımsız Keşfet sayfasında konu, süre ve anahtar kelime filtreleri
- Mobil uyumlu tasarım

## Çalıştırma

Herhangi bir kurulum gerektirmez. `index.html` dosyasını tarayıcıda açın.

## Sıradaki mantıklı ürün adımı

İçerik kartlarını sabit örneklerden gerçek bir içerik kaynağına taşımak ve kullanıcının konum, ilgi alanı ve ayırdığı süreye göre önerileri kişiselleştirmek.
